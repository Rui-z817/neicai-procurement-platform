- 部署密钥：`.workbuddy/neicai_deploy_key`（私钥），公钥已装服务器 root 账户，以后部署全走密钥，不再依赖密码。

## Bug 修复：批量保存接口 500 导致价格"查不到"（同日 11:05）
- 症状：用户上传伟星报价清单后文件存上（1个/13KB）但价格记录 0 条，首页搜索不到。
- 根因：api-server.js 批量接口用了 better-sqlite3 的 `db.transaction()`，**node:sqlite 没有此方法** → POST /api/prices/batch 500（`TypeError: db.transaction is not a function`）→ 前端 batchSavePrices 自动降级把数据写进浏览器 IndexedDB（用户无感知）→ 查询走 server 优先返回空 → 显示 0 条。
- 修复：改用标准 SQL 事务 `db.exec("BEGIN")/COMMIT/ROLLBACK`，上传重启后实测 saved:2/priceCount:2 通过，测试数据已清理。
- 教训：**换 SQLite 库后必须全接口回归测试**，尤其 better-sqlite3 特有 API（transaction/pragma 对象式调用）。
- 用户需重新上传报价清单并保存（上次数据降级写在了浏览器本地，服务器没有）。
