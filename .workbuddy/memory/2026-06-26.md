# 2026-06-26 工作日志

## 内部询价采购平台 开发（全栈Web应用）

### 任务
基于广材网(gldjc.com)页面风格，开发全栈交互系统"内部询价采购平台"。

### 技术栈
- 前端：React 19 + TypeScript + Vite 7 + Tailwind CSS 3.4 + shadcn/ui
- PDF导出：jsPDF + jspdf-autotable
- 数据持久化：localStorage（历史记录）
- 部署：CloudStudio 云沙箱

### 实现的功能
1. **材料分类导航**：12个大类（金属材料、混凝土/砂浆、装饰工程、管材、阀门、电线电缆等），参考广材网分类体系
2. **多维度搜索**：按材料名称、型号规格、品牌、地区、分类查询
3. **市场价展示**：卡片视图 + 表格视图切换，含工程价、供货商、规格参数
4. **信息价列表**：按地区/月份展示最新信息价
5. **PDF报告导出**：一键导出结构化询价报告（含查询条件、市场价明细表、信息价列表、供货商汇总）
6. **历史记录管理**：自动保存所有查询记录，支持单条删除、清空全部、重新查询、从历史导出PDF
7. **UI/UE参考广材网**：蓝色专业风格、搜索栏、分类导航、价格卡片

### 项目结构
- `app/src/types/index.ts` - TypeScript类型定义
- `app/src/data/materials.ts` - 建材数据库（分类、供货商、市场价、信息价）
- `app/src/lib/search.ts` - 搜索逻辑
- `app/src/lib/storage.ts` - 历史记录存储（localStorage）
- `app/src/lib/pdf.ts` - PDF报告生成
- `app/src/sections/Header.tsx` - 头部（品牌+搜索栏+导航）
- `app/src/sections/HomePage.tsx` - 首页（分类导航+最新市场价+信息价）
- `app/src/sections/SearchResultsPage.tsx` - 搜索结果页（筛选+卡片/表格视图）
- `app/src/sections/HistoryPage.tsx` - 历史记录页（删除/清空/重查/导出）
- `app/src/components/PriceCard.tsx` - 价格卡片组件

## 四次迭代：对接南京造价协会真实信息价PDF数据（2026-06-26 14:00）

### 需求
- 用户提供的 http://www.njzjxh.cn/NECACMS/channels/1117.html 上有可下载的PDF信息价
- 要求下载PDF作为数据来源

### 技术挑战
- 该网站使用 SiteServer CMS，页面内容通过 AJAX 动态加载
- 直接 curl/WebFetch 拿不到内容，需模拟 stlDynamic AJAX 请求
- 列表页和详情页都是动态渲染，需两步请求

### 抓取流程（.workbuddy/fetch_njzjxh.cjs）
1. GET channels/1117.html → 提取 templateContent 等参数
2. POST /api/sys/stl/actions/dynamic (JSON格式) → 获取列表HTML
3. 解析列表条目（标题、日期、详情页URL）
4. 翻页抓取（pageNum 1-7），共100条不重复记录
5. 对每条详情页：GET详情页 → 提取参数 → POST AJAX → 获取内容HTML
6. 从内容HTML中提取PDF下载链接（/NECACMS/upload/files/...pdf）

### 抓取结果
- **100条真实信息价记录**（2018年2月 ~ 2026年3月，跨度8年）
- **89条有PDF下载链接**
- 标题格式："南京市二〇二六年三月建设工程材料市场信息价格"
- PDF URL格式：http://www.njzjxh.cn/NECACMS/upload/files/2026/4/3debaf5c5dc087a4.pdf
- 验证：成功下载一个PDF（898KB, application/pdf）

### 系统集成
- `app/src/data/nanjingInfoPrices.ts` - 真实数据文件（100条，含PDF链接）
- `app/src/types/index.ts` - InfoPrice 增加 pdfUrl/isReal 字段
- `app/src/components/InfoPriceSection.tsx` - 重写组件
  - 使用真实抓取数据替代动态生成
  - 最新一期高亮卡片含"下载PDF"按钮
  - 列表每条含"PDF"下载按钮 + "原文"链接
  - 年份筛选器（全部/2018-2026各年）
  - 标签：信息价/官方/真实数据
  - 底部注明数据来源 njzjxh.cn
